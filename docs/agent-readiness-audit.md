## Content and security findings

- `docs/content-fact-check.md` marks several metrics and the phone number as private or unverified. Public content modules already soften claims. Markdown, llms, and search payloads omit the phone and the `needsConfirmation` strings.
- Routed pages still rendered `tel:` links on the home page, contact page, and footer at audit time. `src/lib/seo.ts` still emitted `telephone`. Legacy `src/components/Hero.tsx` and `src/components/Contact.tsx` hardcode a `tel:` link. They are not imported by `src/App.tsx`, are excluded from `tsconfig.app.json` tests, and are not part of the editorial routes.
- Search is a deterministic lexical scan of `searchIndex`. It must not be described as semantic or model-based.
- The API does not fetch caller-supplied URLs, read local files from query input, or accept shell or SQL.

## Tests that already existed

- Vitest: `agentSurfaces` plus the editorial component tests. Baseline on this branch before the gap edits: 14 passed.
- Playwright `e2e/example.spec.ts` still asserts the archived SPA (`#home`, "About Me"). That file is a pre-existing mismatch with the editorial site. Failures there are not regressions of this work.
- `playwright.config.ts` starts `npm run dev` and expects `http://localhost:5173`. If 5173 is already taken, Vite moves to 5174 and Playwright waits on the wrong port.
